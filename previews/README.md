# 디자인 시안

기존 대표 청첩장(`/`)을 유지하면서 시안별 별도 주소를 추가합니다.

| 시안 | 소스 | 배포 주소 |
|---|---|---|
| 1 — 페이퍼 & 로즈 | `previews/test1/` | `/test1.html` |

1번 시안은 https://theirmood.com/card/vzUGuBO4E1 의 날짜 중심 표지, 큰 사진, 종이색 배경, 로즈색 제목과 넓은 여백을 참고해 새 HTML/CSS/JS로 구현했습니다. 참고 사이트의 사진, 문구, 코드, 브랜드 자산은 포함하지 않습니다.

## 빌드와 수정

```sh
node scripts/dist.mjs --build
```

기존 대표 청첩장 빌드가 끝난 뒤 `scripts/build-previews.mjs`가 시안을 추가합니다. 기존 GitHub Actions 명령은 그대로 사용합니다.

- 정보와 사진은 `data/wedding.json`과 `data/images/`를 사용합니다.
- 화면 구성: `previews/test1/index.html`
- 스타일: `previews/test1/style.css`
- 상호작용: `previews/test1/app.js`
- 데이터 연결·HTML 생성: `scripts/build-previews.mjs`
- 생성 결과: `dist/test1.html`, `dist/preview-assets/test1/`
- 기존 `dist/index.html`, `dist/assets/`, `dist/addons/`는 수정하지 않습니다. 시안 출력 경로가 이미 있으면 빌드를 중단합니다.
- 시안은 현재 대표 템플릿 선택과 독립적으로 생성됩니다. 시안 수정은 관리자 배포 버튼이 자동 커밋하지 않으므로 소스 파일을 직접 커밋하세요.
- 대표 사진이 없을 경우 임의의 인물 사진을 넣지 않습니다. 갤러리·연락처 등은 실제 데이터로 구성합니다.
- 참석 여부·방명록은 실제 저장소 주소가 있을 때만 기존 공통 모듈을 통해 표시합니다. 음악·영상도 기존 기능 설정을 따릅니다.
- 카카오 지도·공유는 유효한 키와 도메인 등록이 필요합니다. 새 디자인의 공유 URL은 현재 `test1.html` 주소를 사용합니다.
- 연락처·사진 확대 대화상자는 Escape로 닫을 수 있고, 동작 줄이기 설정을 존중합니다.

## 확인

원본 결과물의 모든 파일 해시를 시안 추가 전후 비교하고, 320/390/768/1440px 화면에서 넘침·이미지 누락과 연락처/사진/계좌 복사/캘린더/메뉴 동작을 확인했습니다. 실제 카카오톡 공유와 지도 앱 실행은 휴대폰에서 확인하세요.

향후 2·3번 시안은 별도 소스 폴더와 출력 경로로 추가합니다. 원본으로 향하는 탐색 링크는 추가하지 않아 하객의 기존 접속 흐름을 유지합니다.
